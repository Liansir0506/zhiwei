# 蓝色界面改版：第一步交付

2026-10-21。本轮统一应用外壳及基础组件；实际修改 static 中的应用文件。

## 已完成

- 品牌蓝统一为 #2563EB，深蓝导航 #14233C，雾蓝灰画布 #F5F7FB。
- 默认导航宽 216px，宽屏 232px，保留用户拖拽/键盘调整及刷新恢复；品牌区固定 88px，导航独立滚动，底部状态固定。
- 顶栏固定 68px，移动端 60px。搜索位置不随问答专属控件出现而移动；证据与历史仍属于局部工作区。
- 页边距、字体、面板、按钮、输入、表格和弹窗使用统一变量；普通控件桌面 40px，移动端 44px。
- 全局导航、品牌和顶栏操作使用统一线性 SVG；替换字符与 emoji 图标。
- 收起导航同步 aria-expanded 与 inert，避免键盘进入屏外导航；保留移动导航、抽屉关闭和侧栏调整交互。
- 修正切页滚动记录读取顺序，保留离开前位置。

## 样式归属

| 文件 | 归属 |
|---|---|
| static/css/tokens.css | 颜色、字体、间距、尺寸、圆角、动效变量 |
| static/css/workspace.css | 全局侧栏、主区域、滚动与问答局部布局 |
| static/css/ui.css | 页头、卡片、控件、表格、提示、通用弹窗 |
| static/css/shell.css | 顶栏、全局搜索/账号/通知及外壳动效 |
| static/css/base.css | 从原内联样式迁出的旧业务内容规则，后续逐页迁移 |
| static/icons.svg | 共用线性图标 |

index.html 的样式资源全部在 head 中加载。已移除内联样式块及 layout-fix.css 的加载，将旧布局补丁并入所属文件。layout-fix.css 只留退役说明，不再参与级联。清除了重复页头、顶栏、侧栏及字号定义；各业务模块仍保留自身内容样式，下一步逐页收敛。
