# 蓝色界面改版：第四步交付与验收边界

2026-10-21。完成统一动效、共享运行环境恢复与主入口真实页面验收。8010 已恢复、后台观察正常；本轮真实验收使用现有 ops 凭据，管理员写流程仍以隔离回归为依据，未实际发布或回滚。

## 已实现并验证

- 页面切换、结果出现、错误反馈、抽屉与遮罩使用统一的短动效，不改变顶栏或侧栏尺寸。
- 原生 details 支持平滑展开与收起；快速反向点击会取消旧动画并恢复自然高度，不留下固定高度或裁切。
- 支持系统“减少动画”偏好；运行中切换该偏好也会结束展开动画。加载状态仍可见，旋转和位移动画停止。
- 查询解析、执行、统计读取、资料提交、版本操作和诊断显示真实请求期间的忙碌状态；没有将动画完成视为业务完成。
- 自定义查询增加“取消等待”；编辑问题、切页或换凭据会取消当前等待并丢弃旧响应；取消不会自动重试，也不宣称服务端已经停止。
- 修复历史会话抽屉打开后切页仍保留键盘拦截的问题；切页关闭抽屉，普通关闭恢复触发按钮焦点。
- 会话管理的全选和删除按钮改用统一浅色控件；真实接口发现 ops 具备任务读取能力，因此将任务可读和资料可写分开控制，ops 保留任务入口并隐藏上传入口。
- 告警断网错误使用明确中文，提供重新加载与运行状态入口，失败时不保留旧表格冒充最新结果。
- 修正启动诊断单元测试仍导入旧 content-quality 运行时的问题，改为当前 r2 入口，避免收集测试时误触历史绑定检查。
