# 数据来源与治理

项目用于个人通信运维训练，不声明客户生产上线。业务数据由生成器构造；第三方资料只保存来源索引及项目自编摘要，不重新分发第三方规范全文。

## 资料准入

每份资料必须核对原文、稳定 source/asset 身份、租户、部门、角色、可见性、适用设备/版本、许可和撤回关系。
正文、身份、权限或目标发生变化时重新审核，不得沿用不匹配的旧批准。
`pending` 或 `draft` 资料不得导入或启用；生成器与自动检查结果不能替代人工批准。
历史审核示例只记录特定资料和目标，不是新环境的授权凭据。

## 候选与发布

先生成独立目录及不可变哈希清单，再在匹配的隔离数据库、集合和 Worker 配置中构建 STAGED。
候选写入使用独立可写暂存区，不改封存候选或原 ACTIVE；任务失败必须有进度、原因、重试与账本。
只有满足来源、权限、元数据、引用定位、门禁和具体发布授权后才能切换，保留可恢复的上一版本。
不得重建原 ACTIVE、将 pending 并行迁移集合启用，或复用旧质量报告证明新候选合格。

## 引用和质量

引用位置必须绑定真实正文及版本：Markdown 行、PDF 页或 CSV 逻辑记录/物理行，不能凭文件名猜测。
撤回、过期、权限冲突和证据不足时应拒绝使用相应资料。通用取证指南不代表型号阈值或完整现场 SOP。
开发题、公开自检和隔离接口测试不等于独立评测；独立题需要真实人员命题、审核及冻结，报告应注明来源、范围和分母。

## 安全与外发

密钥、登录文件、原始语料、批准包、数据库/向量快照和私有评测集不入版本库。
真实手机号、证件、账号及密码在解析阶段脱敏；单元测试中的格式样例仅用于检查脱敏逻辑。
向模型提供方发送问题、会话和检索正文前，应有适用的数据外发许可；本仓库默认关闭生成。

## 训练资料生成

`scripts/generate_enterprise_dataset.py --help` 与 `scripts/validate_enterprise_dataset.py --help` 提供生成和校验入口。
生成使用独立版本和目录，后续仍须逐份准入与候选检查；仓库不附带旧机器的批准状态。
