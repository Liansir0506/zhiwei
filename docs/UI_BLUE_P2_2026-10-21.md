# 蓝色界面改版：第三步交付

2026-10-21。完成实际 static 应用中查询、知识处理和管理页面的操作简化，保留蓝色主调、现有后端接口及权限边界。

## 已实现

| 页面 | 当前操作方式 |
|---|---|
| 业务查询 | 默认进入常用统计，自定义查询独立页签；示例只填入问题；生成后用中文核对对象、过滤、时间范围、排序和条数，再执行只读查询；公式、分母及技术条件可展开查看 |
| 查询异常 | 编辑问题使旧计划失效；修改条数使旧结果失效；延迟响应不会覆盖新问题或新账号；失败可重试，空结果有明确说明；结果保留服务端返回的数据范围，支持导出 |
| 上传与资料 | 拆为上传资料、任务进度、可读文档；上传采用选择文件→核对资料→提交结果；候选创建与绑定详情按需展开；无兼容目标时禁止提交，并提供创建入口 |
| 上传恢复 | 上传失败保留文件、目标和来源标识；本页切换及刷新任务不清除草稿；文档目录失败不再阻断独立上传服务；pending 回执明确仅暂存、未进入问答和未激活 |
| 任务与追溯 | 继续读取 Worker 兼容状态、进度、错误、重试/取消及账本；账本无记录时明确说明；没有以本地成功状态替代服务端状态 |
| 知识库 | 列表突出标题、摘要、来源和查看原文；修订、位置与来源细节折叠；FAQ 跳转只填入问题，不自动发问 |
| 待处理问题 | 默认显示问答问题；案例审核、资料待办、FAQ与回归分开；问题支持认领、补资料、复测、新旧答案对比；只有复测后才提供关闭入口，并要求实际填写解决依据 |
| 版本与发布 | 使用窄版本列表和宽详情；四步展示工程审核、门禁、计划、确认；失败门禁不显示发布计划；重新审核/检查会清理旧计划；重复准备不会累积确认框；当前下一步随流程更新 |
| 发布限制 | 完整配置交接折叠展示；原有仅指针执行限制保留，完整确认文本也不能绕过服务端禁用条件；审计员只读，写操作仍需全局管理员 |
| 运行与评测 | 历史趋势和结构检查默认折叠；无报告时明确显示没有结果；独立评测缺口保留；历史报告不冒充当前版本质量，资料待办不再将“没有报告”显示为“没有失败项” |
| 访问管理 | 首屏展示凭据列表，管理员主动点击才展开签发表单；取消或更换凭据会清除输入的明文；保留原有签发、吊销确认和后端鉴权 |
| 运维账号 | 文档入口直接进入可读文档，隐藏不可用的上传/任务页签；版本仅展示摘要；评测及访问管理导航继续按服务端能力隐藏 |
