# 蓝色界面改版：第二步交付

2026-10-21。已修改实际 static 应用的工作台、告警/工单、诊断与问答页面。

## 页面变化

| 页面 | 已实现 |
|---|---|
| 工作台 | 移除首页大横幅、装饰拓扑和重复模块；保留四项真实接口指标、当前可见范围的待处理事项、短趋势；待办直接进入对应告警，工单指标进入工单页签 |
| 告警 | 更多筛选折叠；详情拆为核对事件、诊断记录、关联工单、处理与验证四区；按需加载，切区保留正在填写的内容，提供显式刷新与返回 |
| 工单 | 草稿字段增加标签；展开后只保留一个建单主操作；建单失败保留输入和重试；状态使用中文，关闭前要求验证说明，服务端继续决定是否允许关闭 |
| 恢复验证 | 点击后才填写指标、处理后值、正整数观察分钟与明确结论；未选择结论不提交；观察失败不出现解决动作，通过后才按服务端 next_actions 展示解决 |
| 诊断 | 问题与关联对象分层；模式说明收敛；结果生成后折叠输入条件，突出判断和复核；证据、观测、工具记录按需展开；人工复核不标为自动完成 |
| 诊断衔接 | 驳回/需补证不能正式确认；确认请求继续绑定 run；成功后提供“去告警继续处理”；导出为次操作；切页后保留诊断草稿及结果，换凭据时清除 |
| 问答 | 空态只展示三道来自当前可读接口的推荐；知识版本靠近输入区；正文保持阅读宽度；证据全宽度使用抽屉；原文只在主动点击时读取，继续逐次鉴权 |
| 问答草稿 | 草稿保存在当前浏览器标签页的 sessionStorage，按凭据指纹及会话分区；切页/切会话可恢复，提交失败后可编辑与重试；推荐点击只填入，不自动提交 |

同时修正实验室页嵌套在访问管理页内的原有 HTML 结构问题。所有视图现在是主区域内的同级页面。

## 验证结果

- 196 项 Edge 浏览器检查通过；0 个 JS 异常、0 个静态资源缺失、0 次未预期业务请求。
- 覆盖 14 个页面的实际可见性、桌面及 390px 窄屏、外壳尺寸、侧栏、弹窗、草稿、错误重试、来源抽屉。
- 告警→诊断→复核→建单→工单受理→恢复观察→解决→工单关闭走通；建单失败后重试、空关闭说明、恢复前关闭、观察缺字段/负数分钟、观察失败、复核驳回均检查。
- QA 推荐不自动提交；完成回答不预取原文；主动点击选中引用后读取一次；失败问题保留；历史会话关闭恢复焦点。
- 15 项现有后端单元测试通过，覆盖告警状态转换与诊断判断。
- 原有 243 个 DOM 标识及所有业务脚本入口保留，无重复 ID；应用模块及内联脚本均通过 Node 语法检查。

浏览器使用**实际应用 HTML/CSS/JS + 独立进程内状态接口样例**，流程写请求只改变测试内存，不连接真实数据库、设备或模型。上述结果证明界面与接口契约衔接，不等同于真实服务、数据库、模型答案质量或生产验收。没有新增真实模型调用、资料准入、发布或 8010/8011 切换。
